# HELLO, UNIVERSE

高校生に「コードでここまで作れる」を見せるための、インタラクティブ作品集です。
画像も動画も使っていません。すべて数式と GPU の計算だけで描かれています。

**公開URL: https://wakabayashi-agent.github.io/hello-universe/**

## 収録作品

| | 作品 | 中身 |
|---|---|---|
| 01 | 言葉から生まれる宇宙 | 入力した文字を26万個の粒子が形づくり、崩れて銀河になる（GPGPU パーティクル） |
| 02 | 指先の流体 | マウスの動きが渦を巻いて滲む（Stable Fluids をGPUで解く） |
| 03 | 無限フラクタル | マンデルブロ集合を約260億倍まで拡大できる（摂動法） |
| 04 | 重力の庭 | クリックで星を置くと引力で軌道を描く（N体シミュレーション） |
| 05 | 雷鳴 | クリックした場所へ、毎回その場で生成される稲妻が落ちる（中点変位法による分岐生成 + HDR ブルーム） |
| 06 | 百万匹の粘菌 | 最大100万のエージェントがフェロモンだけで血管網を自己組織化する（Physarum シミュレーション） |
| 07 | 地下の星座 | 東京メトロ9路線・約180駅を3D化し、加減速つきの光の列車が運行する（時刻表シミュレーション） |
| 08 | うごく太陽系儀 | JPLの軌道要素で8惑星が今日の配置から回る。惑星表面は全て手続きシェーダ（ケプラー軌道計算） |

## 使い方

トップページの文字は URL で差し替えられます。

```
https://wakabayashi-agent.github.io/hello-universe/?text=好きな言葉
```

改行したいときは `%0A`（改行のURLエンコード）を挟みます。

## 開発

```bash
npm install
npm run dev
```

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバを起動 |
| `npm run build` | `dist/` に本番ビルド |
| `npm run preview` | ビルド結果をローカルで確認 |
| `npm run typecheck` | 型チェック |

`main` に push すると GitHub Actions が `dist/` を GitHub Pages へ公開します。

## 構成

```
src/
  core/      WebGL コンテキスト・描画ループ・品質調整・GPGPU の土台
  works/     8作品。それぞれ独立していて、共通の Work インターフェースを実装する
  gallery/   トップページ
  ui/        画面まわりの小さな部品
```

作品は動的 import で分割されているので、開いたページに必要なコードだけが読み込まれます。

### 動作環境

WebGL2 と浮動小数点テクスチャへの描画が必要です（現行の Chrome / Edge / Firefox / Safari で動作）。
端末の性能に応じて粒子数とシミュレーション解像度を自動で調整し、
フレームが落ちる場合は描画解像度も段階的に下げます。
